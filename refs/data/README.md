Reference data pulled during Phase 0 research (22 Aug 2026).

- `netlib_readme.txt` — netlib.org/lp/data/readme. Instance table with reference
  optimal objective values, plus the degeneracy statistics and conditioning notes
  cited in RESEARCH.md section 5.1.
- `mm_readme.txt` — doc.ic.ac.uk/~im/00README.QP. Maros-Meszaros convex QP set:
  problem list with sizes and reference optima.
- `miplib_bench.txt` — miplib.zib.de benchmark-v2.test, the 240 MIPLIB 2017
  benchmark instance names.
- `miplib.solu` — miplib2017-v29.solu, reference solution values for MIPLIB 2017.
- `mittelmann_lpfeas_2026-08-10.html` — Mittelmann LPfeas benchmark results,
  the GPU-vs-simplex comparison quoted in RESEARCH.md section 5.2.
